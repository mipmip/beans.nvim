1. INTRODUCTION                                             *beans-introduction*

beans.nvim opens a small near-cursor wizard when the Beans TUI creates a bean in
your $EDITOR, letting you set the frontmatter fields (status, type, priority,
tags, parent) with single keystrokes, then drops you into the body in insert
mode. All edits are made directly in the buffer, so each field is one undo step.

See beans-nvim-briefing.md in the repository for the complete design spec.

==============================================================================
2. SETUP                                                          *beans-setup*

>lua
    require("beans").setup()
<
setup() with no arguments yields the intended experience. Partial option tables
merge over the defaults; an invalid value warns once and falls back.

==============================================================================
3. THE WIZARD                                                     *beans-wizard*

Steps, in order: status, type, priority, tags, parent.

The wizard auto-starts on a freshly created bean (created_at within
`autostart.max_age_seconds` and an empty body). Otherwise use |:BeanWizard|.

Interaction differs by field kind (a deliberate, documented inconsistency):
  - status/type/priority: press a letter to select + confirm + auto-advance.
  - tags: <Space> toggles, `n` adds a new tag, <CR>/<Tab> confirm.
  - parent: type to filter, <C-n>/<C-p> move, <CR> selects.

Universal keys: <Tab> accept+advance, <S-Tab> back, <CR> select, <Esc>/q finish.

==============================================================================
4. COMMANDS                                                     *beans-commands*

                                                                    *:BeanWizard*
:BeanWizard        Start the wizard at step 1.

                                                                          *:Bean*
:Bean              Field menu, then value picker.
:Bean {field}      Jump straight to one field (completes on field names).

:checkhealth beans Diagnostics; see |beans-health|.

==============================================================================
5. KEYMAPS                                                       *beans-keymaps*

Buffer-local, bean buffers only (disable with `keymaps.enabled = false`):

  <leader>bw   start wizard
  <leader>bb   field menu
  <leader>bs   status        <leader>bt   type        <leader>bp   priority
  <leader>bg   tags          <leader>bP   parent

==============================================================================
6. CONFIGURATION                                                  *beans-config*

The complete default table is documented in beans-nvim-briefing.md §7.3. Merge a
partial table via setup(); siblings are preserved.

==============================================================================
7. HEALTH                                                         *beans-health*

`:checkhealth beans` reports the beans binary and version, the project root and
bean directory, whether the current buffer is recognised (and why not if it is
not), the discovered vocabularies, and cache state.
